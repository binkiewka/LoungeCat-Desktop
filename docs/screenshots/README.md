## Capture details

Captured on 28 October 2026 with Qt 6.4.2. These are application screenshots
rendered using Qt's offscreen backend and `QWidget::grab()`, without window-manager
borders. A disposable profile and local IRC fixture supplied fictional demo data.
A capture driver selected themes and settings through existing widget controls;
the application code and rendering were unchanged.

Theme images are 1440 × 900, the four-pane view is 1920 × 1080, and settings
views are 850 × 580. The [capture manifest](capture-manifest.json) records the
source revision, executable hash and image checksums.
